## 6. Postman (API Client)

**Why:** Postman lets you send API requests by hand (GET, POST, PUT, DELETE…) and see the response (status code, headers, body). In API testing we first **explore an API manually in Postman**, then **automate the same checks with Playwright**.

**Download:** https://www.postman.com/downloads/

**Requirements (Windows):** Intel 64-bit or ARM 64-bit.

**Install steps (Windows):**
1. Download the latest Postman version for Windows from the download page.
2. Select and run the **`.exe`** file to install Postman.
3. Postman opens when the installation finishes.

**Sign in or not?**
- **Without signing in:** you get the **lightweight Postman API Client**, which is enough to send requests and see responses.
- **With a free account:** you can save requests in collections and sync your work across devices.

**Web version (alternative):** Postman can also run in the browser without installing anything. It needs a free account. Open https://www.postman.com/downloads/ and choose the web option.

**Check it's installed:** Open **Postman** from the Start menu. If the app starts, it's installed.

> Postman has no terminal command like `node -v`, so there is no command-line version check.
